# 写作任务

先读本项目写法卡、事实库和对应素材，再读技能写作参考。一个任务对应一个需要作出的经营决定。

| 项 | 内容 |
|---|---|
| 内部稿件 ID 和版本 | |
| 题号及冻结原题 | |
| 读者经营阶段 | |
| 读者要作出的决定 | |
| 拟用平台、账号 | |
| 已有作品 ID、公开 URL | |
| 补缺任务编号、证据位置 | |
| 旧稿已提供的经营动作 | |
| 本稿新增动作 | |
| 新输入和新产出 | |
| 哪种情况不适用 | |
| 采用修订旧稿或新稿的理由 | |
| 使用事实及素材编号 | |
| 品牌出现的用途、拟核验品牌段 | |
| 配图及来源 | |
| 平台声明安排 | 按当前实际要求填写 |
| 人工审稿状态和版本 | 待审 |

旧动作、新动作实质相同，先返回选题或修订旧稿。不凭标题差异放行。不同品牌沿用这张表，不能套用其他项目的课程、履历、地址或权益。

稿件之外附 `稿外证据.csv`。交稿后把审定的回答段、品牌段及硬事实段写入 `发布核验.json`。字数检查沿用 `check_article.py`；它只查已知错误和机械统计。
