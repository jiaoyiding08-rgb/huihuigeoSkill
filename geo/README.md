# GEO Loop Pro 1.0 使用说明

作者：汇汇

这套技能服务多个品牌，沿用资料、问题、检测、分析、写作和发布五步。品牌项目单独存放。

## 试用

1. 解压后保留 `geo/`。按你的 AI 工具支持的方式加载本地技能，并选择品牌项目。
2. 让 AI 先读项目的 `AGENTS.md` 和 `GEO状态.md`。已有项目接着做，不重建题库或台账。
3. 首次只选两道题。批次初始化支持中文或英文表头，`--repeats 3` 为每题每平台准备三个独立样本。
4. 原始提取放 `answers/`，复核结果另放 `observations/`。先映射引用、查缺项，再决定内容改动。
5. 稿件经人工审稿后发布，保留作品 ID、公开 URL 和段落核验记录。复测按实验卡执行。

脚本和字段说明见 `references/7_证据与复测.md`。未取得原题、原会话、正文或落地网址时，允许完成材料分析和离线检查，不得把它们算作真实采样效果。

## 如何理解结果

公开可读、爬虫访问、搜索收录、参考列表出现、正文引用、品牌提及、品牌推荐和硬事实正确分别记录。平台在某个批次偏向某类来源，只能作为后续选渠道的线索。内容体裁、配图或单独品牌段是否提高引用，需要独立复测。

新版本保留原脚本入口与旧台账列。单次批次默认任务编号不变。发行说明见 GitHub 的 v1.0.0 发布页。品牌资料由各项目单独维护。
